# ⚽ Ball Brawl

**Ball Brawl** is a 2D ball-based game developed using **C# and Windows Forms**. The project focuses on building interactive gameplay while learning the fundamentals of game development, including movement, collision detection, event handling, and game logic.

## 🎮 About the Game

Ball Brawl is a personal game development project built to explore how games can be created using C# and the .NET Windows Forms framework.

The project is an opportunity to practice programming concepts in a hands-on environment while gradually developing the game's mechanics, interface, and overall experience.

## 🛠️ Built With

- C#
- .NET / Windows Forms
- Visual Studio

## ✨ Features

- Interactive 2D gameplay
- Ball movement and control
- Collision detection and game physics
- Windows Forms graphical user interface

*Features are subject to change as development continues.*

## 🚀 Getting Started

### Prerequisites

- Windows
- Visual Studio with the .NET desktop development workload
- A compatible .NET SDK

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR-REPOSITORY-URL>
   ```

2. Open the solution file (`.sln`) in Visual Studio.

3. Restore any required dependencies.

4. Build and run the project.
